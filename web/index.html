    07Privacy

    The report boundary

    How skuggsja handles your data, paths, and local files.

    Data handling

    Analysis runs on this machine. The report is derived from local artifacts and served on loopback; nothing is sent anywhere.

    What is stored

    Aggregate timestamps, counts, model labels, project basenames, coverage notes, and source-audit digests. Privacy-reduced, not anonymous.

    What is not stored

    Raw prompt text, file contents, source paths, and session or call identifiers. Prompt lengths are counted in memory and then discarded.

    Access mode

    Every source handle is opened read-only. skuggsja never writes to, moves, or creates files in your repositories.

    Source boundary

    Your data stays on your machine. skuggsja only reads what’s already there.

    08Method

    Definitions & caveats

    What skuggsja includes, what it doesn’t, and how to interpret the report.

    What this is

    skuggsja is a local, read-only report that reconstructs your work with AI coding tools from local artifacts. It summarizes activity, prompts, projects, and file references so you can read back your own working record.

    Local history is not lifetime usage.

    This report reflects only locally available data from supported tools on this machine. It may be incomplete due to tool settings, data retention, or missing local history.

    What’s included

    • Local artifacts from the supported harnesses: Claude Code, Codex, Hermes Agent, and Cursor
    • Sessions, prompts, projects, and source-file references, reduced to aggregates
    • Activity timelines and simple statistics from recorded times
    • Per-harness tool-call and model-event counts in native units

    What’s not included

    • Raw prompt or transcript text; lengths are measured in memory and discarded
    • File contents or absolute file paths
    • Data from cloud services, remote accounts, or unsupported tools
    • Network activity, uploads, or telemetry

    How to interpret

    • Counts represent recoverable local records, not absolute truth
    • Timelines show when activity was recorded locally, in this machine’s timezone
    • Project names come from local data and may be approximate
    • Use the report as a starting point for reflection, not an audit log

    Limitations

    • Results depend on tool configuration and on how long each tool retains history
    • Some activity may be missing or only partially reconstructed
    • Harness counts stay separate; they are never summed or ranked across tools
    • skuggsja does not write to source paths and makes no changes to your data
